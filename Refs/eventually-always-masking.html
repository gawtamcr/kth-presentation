The trajectory and its predicate

Teal band is the goal x ≥ 5. The predicate margin is s(t) = x(t) − 5 — positive once the path is inside the band.

Plain Eventually — one column is all that's used

The masking grid computes a value for every starting time t (teal outline = column 0). Because φ₁ sits at the top of the formula, nothing ever reads the other columns — only column 0's window matters.

ρ(φ₁) = max(s₇,s₈,s₉,s₁₀)—
φ₂ · 1

Inner Always[0,2] — now every column is needed

The outer Eventually needs to know, for every starting time t, whether an always-safe window begins there. So this time the full trace is the answer, not one column. Columns whose window runs past the horizon get padded cells (italic), filled with a very large value so they can never be the minimum.

φ₂ · 2

Outer Eventually[0,10] — reduces the inner trace

The outer operator's "signal" is no longer x(t) — it is the inner trace computed above. When its window spans the whole horizon this reduction needs column 0 only, same as φ₁ — but reading from the trace, not from x directly. Shrink the window below and it stops being the whole horizon — then column 0 alone is no longer enough, and you'd need to look at later columns too.
